Generate a highly scalable, Web3-integrated, modular, and all-encompassing ERP system designed for both NGOs and businesses of all sizes. This system must be built using Next.js (frontend), Node.js (backend), and Prisma with MongoDB (database).

🎯 High-Level System Architecture
Frontend: Next.js with Tailwind CSS (for modern UI/UX).
Backend: Node.js with Express.js (REST API structure).
Database: Prisma ORM with MongoDB (for flexibility and scalability).
Authentication & Roles: JWT-based authentication with different user roles:
Super Admin: Highest authority (e.g., business owner, NGO director).
Admin: Business-level administrator managing users and settings.
Employee/User: General user with restricted access.
Guest: Temporary users with view-only access (if applicable).
Static Data First: The MVP should use static data while maintaining dormant API endpoints that will be activated once the backend is fully integrated.
